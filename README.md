# 🚀 Front-end do Projeto Intercessão

Este é o front-end do **Projeto Intercessão**, desenvolvido com as tecnologias **React**, **Next.js**, **TypeScript** e **Tailwind CSS**.

---

## 🧰 Stack Utilizada

- ⚛️ **React**
- 🌐 **Next.js**
- 🟦 **TypeScript**
- 💨 **Tailwind CSS**

---

## 📦 Como rodar o projeto localmente

1. **Clone este repositório**:

```bash
git clone https://github.com/SophionDataTech/front-end_inter.git
```

2. **Acesse o diretório**:

```bash
cd front-end_inter
```

3. **Instale as dependências**:

```bash
npm install
```

4. **Inicie o servidor de desenvolvimento**:

```bash
npm run dev
```

A aplicação estará disponível em: [http://localhost:3000](http://localhost:3000)

---

## ✨ Scripts disponíveis

| Comando        | Descrição                               |
|----------------|-------------------------------------------|
| `npm run dev`  | Inicia o servidor de desenvolvimento      |
| `npm run build`| Cria a versão de produção do projeto      |
| `npm run start`| Inicia a aplicação já em produção         |
| `npm run lint` | Executa o linter para checar problemas    |

---

## 🎨 Estilização

O projeto utiliza **Tailwind CSS**, um framework utilitário de CSS para criação rápida de interfaces responsivas e modernas.
